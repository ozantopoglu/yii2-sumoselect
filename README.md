# yii2SumoSelect
=============
Sumo Select widget for Yii 2 framework

Installation
------------

The preferred way to install this extension is through [composer](http://getcomposer.org/download/).

Either run

```
composer require ozantopoglu/yii2-sumoselect
```

or add

```
"ozantopoglu/yii2-sumoselect": "*"
